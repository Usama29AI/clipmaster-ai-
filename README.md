# 🎬 ClipMaster AI

**ClipMaster AI** is an AI-powered SaaS web application designed for solo creators to turn long-form videos into viral short clips (TikTok, YouTube Shorts, Instagram Reels).

## 🚀 Features
- ✂️ **Automatic Video Clipping:** Extract high-retention hook moments automatically.
- 🗣️ **Auto Subtitles & Captions:** Support for Urdu (اردو), English, and Bilingual captions.
- 📱 **9:16 Shorts Export:** Convert horizontal videos into vertical 9:16 aspect ratio.
- 📊 **AI Viral Score:** Intelligent scoring for extracted video clips.
- ⚡ **Mobile First:** Fully functional, lightweight interface optimized for mobile and desktop devices.

## 🛠️ Tech Stack
- **Frontend:** HTML5, Tailwind CSS (CDN), JavaScript (ES6+)
- **Hosting:** Vercel / GitHub Pages
- **Repository:** Public GitHub Open Source
